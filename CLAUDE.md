# BackupOrim — CLAUDE.md

## Project Overview

A desktop GUI application that creates ZIP or RAR archives of selected folders, copies them to a destination, and automatically cleans up old backups based on a retention policy.

**Target platform:** Windows 10/11  
**Language:** Python 3.11+ (dev); built with Python 3.12 on GitHub Actions  
**GUI toolkit:** tkinter (standard library) — pure `tk` widgets for full color control, `ttk` only for Scrollbar and Combobox  
**Distribution:** Single `.exe` built by PyInstaller via GitHub Actions on every `v*` tag push  
**Repository:** https://github.com/Orimslav/Backup_tool.git  

---

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python backup_app.py
```

`requirements.txt` contains: `pyzipper`, `pystray`, `Pillow`, `winotify`.  
`pyinstaller` is installed by the GitHub Actions workflow — not in requirements.txt.

## Distribution — PyInstaller

### Spec file: `BackupOrim.spec`

Key settings:
- `datas=[('img/', 'img/')]` — bundles the entire `img/` folder
- `console=True, hide_console='hide-early'` — **workaround for Python 3.14**: `console=False` (windowed subsystem) silently crashes on Python 3.14 with PyInstaller 6.x; `hide_console='hide-early'` achieves the same result (no visible console) while using the console subsystem which works correctly
- `upx=False` — avoids UPX-related crashes
- Hidden imports: `pystray._win32`, `pyzipper.zipfile_aes`

### Resource path helper — `_res()`

All `img/` paths in `backup_app.py`, `tray.py`, `notifications.py` use:

```python
def _res(rel: str) -> Path:
    base = Path(getattr(sys, "_MEIPASS", Path(__file__).parent))
    return base / rel
```

`sys._MEIPASS` is set by PyInstaller to the temp extraction directory when running as a frozen exe.

### Autostart in frozen exe

`_pythonw()` and `_script_path()` in `BackupApp` detect frozen mode:

```python
def _pythonw(self) -> str:
    if getattr(sys, "frozen", False):
        return sys.executable   # the .exe itself handles --autorun
    return str(Path(sys.executable).with_name("pythonw.exe"))

def _script_path(self) -> str:
    if getattr(sys, "frozen", False):
        return ""               # no separate script; exe is self-contained
    return str(Path(__file__).resolve())
```

`autostart._build_cmd()` handles empty `script_path`:
```python
def _build_cmd(python_exe, script_path, flags):
    if script_path:
        return f'"{python_exe}" "{script_path}" {flags}'
    return f'"{python_exe}" {flags}'
```

### Error capture in windowed exe

`_early_excepthook` is installed as `sys.excepthook` at the very top of `backup_app.py` (before any other imports) to catch import-time crashes and write them to `%APPDATA%\OrimslavBackup\startup_error.txt`.

`_guarded_main()` wraps `main()` with a try/except that also writes the error file and shows a `messagebox.showerror` dialog.

### GitHub Actions workflow: `.github/workflows/build.yml`

Triggers on `push` to tags matching `v*`. Steps:
1. `actions/checkout@v4`
2. `actions/setup-python@v5` with Python **3.12** (stable PyInstaller support)
3. `pip install -r requirements.txt && pip install pyinstaller`
4. `pyinstaller BackupOrim.spec --clean`
5. `softprops/action-gh-release@v2` — creates GitHub Release, uploads `dist/BackupOrim.exe`, auto-generates release notes

To trigger a release:
```bash
git tag v1.0.0
git push origin v1.0.0
```

## Functional Requirements

### 1. Source folders
- Multiple source folders via folder-picker. Listbox + scrollbar. "Remove selected" removes highlighted entry. Duplicate paths silently ignored.

### 2. Destination
- Single destination folder. Created if missing. Must not be inside any source folder.

### 3. Archive format
- ZIP (default) or RAR radio buttons.
- ZIP: `pyzipper.AESZipFile` with AES-256 if password set, else stdlib `zipfile.ZipFile` with `ZIP_DEFLATED`.
- RAR: external `rar.exe`. Auto-detected at `C:\Program Files\WinRAR\rar.exe` and `(x86)` variant. User can override path.

### 4. Password protection
- Entry field (`show="*"`) + "Show password" toggle.
- ZIP: `pyzipper` AES-256. RAR: `-hp<password>` flag (encrypts contents + file names).
- **Never log the password.** Mask as `-hp***` in any log output.
- "Remember password" checkbox: unchecked = session-only; checked = saved to config (plaintext warning shown).

### 5. Archive naming
```
<source_folder_name>_<YYYY-MM-DD_HH-MM-SS>.<zip|rar>
```

### 6. Cleanup policy
Three radio options: None / Keep last N / Delete older than N days. Runs after each successful backup per source.

### 7. Configuration persistence
Saved to `%APPDATA%\OrimslavBackup\config.json` on "Save settings". Loaded automatically on startup.

### 8. Threading & logging
- Backup in `threading.Thread(daemon=True)`. Log writes via `root.after(0, ...)`.
- `scrolledtext.ScrolledText` log widget with colored tags: ok=green, err=red, info=blue, ts=dim gray.
- Mirrored to `%APPDATA%\OrimslavBackup\backup.log` via `RotatingFileHandler` (5 MB × 3).

### 9. Language switcher
- Flag images (SK / EN) in header. Clicking sets language.
- `_translatable` list of `(widget, attr, key)` iterated on switch.
- Both language tables must have identical keys (asserted at import time in `i18n.py`).

### 10. Autostart
- **Logon**: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` via `winreg`. No admin required.
- **Scheduled**: Task Scheduler daily/weekdays/weekly. Task name: `OrimslavBackup-Scheduled`.
  - Frequency combobox (`ttk.Combobox`, `width=16`): Every day / Weekdays / Weekly on…
  - When "Weekly on…" is selected, a day-of-week row appears with 7 checkboxes (Mon–Sun / Po–Ne). Default: Monday.
  - Selected days stored in `config.json` as `scheduled_days` (list of schtasks codes: `["MON"]`, `["MON","WED"]`, etc.).
  - Passed to `autostart.enable_scheduled(..., days=[...])` which builds `/SC WEEKLY /D MON,...`.
- All use `_build_cmd(python_exe, script_path, flags)` which handles empty `script_path` (frozen exe).
- **Logon** registers `--minimized --autorun`: app starts in tray, then `root.after(3000, app._run_backup)` triggers backup after 3 s.
- **Scheduled task** registers `--autorun` only. If the GUI is already running (lock held), the second instance cannot acquire the lock — instead it writes `app.backup_request` sentinel file and exits with code 0. The running GUI polls this sentinel every 500 ms in `_poll_show_request()` and calls `_run_backup()` when detected.

### 11. System tray
- `pystray` + `Pillow`. Icon: `img/orimslav_logo_blue_transparent.ico`.
- Minimize to tray on close (if enabled). Right-click menu: Show / Run now / Open log / Exit.
- Tray on daemon thread; communicates with main thread via `root.after(0, ...)`.

### 12. Toast notifications
- `winotify`. Success and failure toasts with configurable opt-in/opt-out checkboxes.

### 13. Single-instance guard
- Lockfile at `%APPDATA%\OrimslavBackup\app.lock` with running PID.
- PID-alive check via WinAPI (`OpenProcess` + `GetExitCodeProcess`) — no psutil dependency.
- Second GUI instance signals show-window (`app.show_request` sentinel file) and exits.
- Second `--autorun` instance (scheduled task) signals backup-request (`app.backup_request` sentinel file) and exits with code 0.
- `_poll_show_request()` runs every 500ms via `root.after`, checks both sentinels. The after-ID is stored in `self._poll_after_id` and cancelled in `_quit_app()` before `root.destroy()` to prevent `KeyboardInterrupt` on exit.

### 14. Exclude patterns
- Multi-line Text widget, one glob per line.
- Matched against directory names (prunes `os.walk`) and file names during ZIP creation.
- RAR: translated to `-x` arguments.

### 15. Integrity check
- ZIP: `zipfile.ZipFile(path).testzip()`. RAR: `rar t <path>`.
- On failure: delete the bad archive, raise RuntimeError, skip cleanup.

### 16. Last-run status
- `%APPDATA%\OrimslavBackup\last_run.json` with timestamp, result, message, duration.
- Shown in status bar below tab content. Red foreground on error.

### 17. Shutdown after backup
- Checkbox "Vypnúť PC po zálohe / Shut down PC after backup" in the action row (right of Save, left of Run).
- **Session-only** — intentionally not saved to `config.json`. Prevents automatic scheduled runs from shutting down the PC.
- Triggers only on successful backup: runs `shutdown /s /t 60` (60-second delay so user can cancel via `shutdown /a`).
- Logs an info message with cancel instructions.

## Running

```powershell
# From source
python backup_app.py

# Headless autorun — scheduled task (GUI not running)
BackupOrim.exe --autorun

# Autorun + shut down PC 60 s after successful backup
BackupOrim.exe --autorun --shutdown-after

# Start hidden in tray (no backup)
BackupOrim.exe --minimized

# Start hidden in tray + trigger backup after 3 s — used by logon autostart
BackupOrim.exe --minimized --autorun
```

Exit codes: `0` = success, `1` = backup failed / validation error, `2` = another instance already running (headless `--autorun` only).

## Known Issues / Gotchas

- **Python 3.14 + PyInstaller windowed mode**: `console=False` silently crashes. Workaround: `console=True, hide_console='hide-early'`. GitHub Actions uses Python 3.12 which doesn't have this issue.
- **Stale lock file**: If the process is killed hard (not via `_quit_app`), the lock file remains. On next start, `_is_pid_alive()` detects the stale PID and takes over — this is correct behavior.
- **`logging.basicConfig` level=DEBUG**: Pillow emits many DEBUG-level PNG/ICO stream messages to the log. This is cosmetic only; the log rotates at 5 MB.

## Out of Scope

- Incremental / differential backups
- Cloud destinations (OneDrive, S3, Synology NAS)
- Languages other than EN / SK
- Group Policy shutdown scripts (requires admin + Pro/Enterprise)
- Pre/post backup hooks
- VSS (Volume Shadow Copy) for open files
- Concurrent multi-source backups (currently sequential)
